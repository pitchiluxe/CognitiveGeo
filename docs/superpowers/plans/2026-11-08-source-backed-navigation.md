# Source-backed navigation and intelligence plan

**Goal:** Remove synthetic runtime/security displays and make every sidebar route useful for AI research and delivery.

**Architecture:** Replace the legacy controller and globe runtime machinery with a source-only explorer shell. Add overview, security, agents, creative workflows, adoption observations, niche discovery and actual workspace activity views, reusing existing country/idea/client tools. Share fixed-host advisory adapters between Vite, Electron and Vercel; bundle a dated official-source fallback.

## Requirements

- Delete mock runtime data, invented attacks, metric growth, synthetic event timers, forecast playback and procedural city infrastructure.
- Keep the globe as geographic visualization. Display only source-linked locations or explicitly user-entered/planned locations; never infer attack origins.
- Retain all working atlas, facility, country, studio, ideas, models, history and Ollama functions.
- All rail icons route to working views with active state, accessible names, keyboard access and responsive scrolling.
- AI user metrics retain exact metric, period, population, publisher and methodology. Unknown counts remain unknown; percentages are not multiplied into invented user totals.
- Agents/creativity provide real editable, copyable, downloadable briefs and actual local-model handoffs, not pretend executions.
- Security shows official advisories, explicit source freshness, bounded validated user inventory and exact CVE matches. No scanning, invented mitigation or compliance claims.
- Activity records user actions/source refreshes, never made-up security events.

## Work

1. Add tested advisory normalization, exact inventory matching, source snapshots and fixed-host API adapters.
2. Replace runtime-heavy main/globe and discovery routing; remove legacy data/tests and update landing copy.
3. Add AI agent, creative, adoption, niche, overview and activity views and sidebar icons.
4. Verify every route and its primary actions, existing client journey, source/error behavior, responsive layout and absence of runtime simulation. Review, commit/push and verify web/Windows publication.
